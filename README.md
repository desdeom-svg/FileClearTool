# 磁盘清理助手 (Disk Cleaner Assistant)

一款基于 Python + CustomTkinter 开发的 Windows 自动化后台磁盘清理工具。它可以监控磁盘剩余空间，并在空间不足时自动清理指定文件夹内的最旧文件。

## 核心功能
- **多驱动器监控**：支持监控系统任意盘符。
- **空间阈值预警**：自定义最小剩余空间（GB）。
- **智能文件删除**：按时间先后排序，逐个删除最旧文件，而非直接删除整个文件夹。
- **动力回收模式**：可选择将文件移入自定义的“回收站”目录而非直接永久删除。
- **空目录回收**：自动清理清理路径下的空文件夹。
- **系统托盘驻留**：关闭主界面后可最小化至系统托盘继续后台运行。
- **持久化配置**：配置保存于 `config.json`，并持久化运行日志。

## 技术栈
- Python 3
- CustomTkinter (GUI)
- psutil (磁盘监控)
- pystray (系统托盘)
- PyInstaller (打包成单文件 EXE)

## 如何运行
1. **源码运行**：
   ```bash
   pip install customtkinter pystray pillow psutil
   python main.py
   ```
2. **打包运行**：
   项目已包含 `build.bat` 脚本，可一键生成独立 EXE 文件。

## 注意事项
- 建议将清理路径指向临时文件夹（如日志、缓存、视频录制分片等）。
- **警告**：该工具在非回收站模式下会永久删除文件，请务必确认清理路径的安全性。
